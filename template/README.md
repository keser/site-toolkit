# <Site name>

Permaculture site analysis and design workspace for <site>. **Private repo.** Created from
`site-toolkit/template/`.

## First steps
1. Fill in `CLAUDE.md` (owner, stakeholders, privacy rules for this site).
2. Interview the stakeholders and fill in the People and Goals sections of `site-plan/design-brief.md`.
3. Start `site-plan/site-profile.md`. Its sections list the questions to answer and the data to
   collect, and each links to the finished example in the toolkit demo.
4. Define phases in `site-plan/phases.md` from the goals and constraints, then add tasks to
   `site-plan/tasks.md`.
5. Keep `site-plan/progress-log.md` as you go.

## What's in `site-plan/`
| File | What it holds |
|---|---|
| `site-profile.md` | The site as it is: context, climate, sun, sectors, hazards, landform, water, soil, vegetation, microclimates, current zones |
| `design-brief.md` | Who it's for, their goals, and the design layers that answer them |
| `phases.md`, `tasks.md` | Phases defined for this site, and tasks with IDs and dependencies |
| `progress-log.md` | Dated narrative, newest first: what happened and why the plan changed |
