# Phases

Define phases from this site's design goals and constraints. They need not run in sequence;
some can run alongside others (as "Design" does in the example below). Give each a short ID prefix.

| Prefix | Phase | Scope | Notes |
|---|---|---|---|
| | | | |

## Example (not a prescription)
The demo property used five: `R` Reset (clearing, mulching, reorganizing), `C` Construction
(water line, electrical, shed), `S` Establish Systems (compost, water harvesting), `D`
Diversity & Habitat (native plantings), and `DS` Design (ongoing, runs alongside the others).
That fit one renovation-heavy 0.43-acre lot. Another site might be organized by zone, season,
budget tier, or client priority instead.
